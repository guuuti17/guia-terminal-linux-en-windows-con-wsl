# 🐧 Guía de instalación de WSL (Windows Subsystem for Linux) en Windows

Esta guía explica cómo instalar WSL en Windows 10 o Windows 11 para usar una terminal Linux integrada.

---

## 📋 Requisitos

- Sistema operativo: Windows 10 (versión 2004 o superior) o Windows 11.
- Acceso a una cuenta con privilegios de administrador.

---

## 🔧 Paso 1: Abrir PowerShell como administrador

1. Pulsa `Inicio`.
2. Busca **"PowerShell"**.
3. Haz clic derecho sobre "Windows PowerShell" y selecciona **"Ejecutar como administrador"**.

---

## 🚀 Paso 2: Ejecutar el comando de instalación de WSL

En la terminal de PowerShell, ejecuta:

```powershell
wsl --install
